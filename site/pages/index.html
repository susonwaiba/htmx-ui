Do I need a JavaScript framework?

No. Components are CSS classes; a few have small behaviours that re-run after htmx swaps.

Does this accordion use JavaScript?

No, it's a native <details> element. Only one item opens at a time because they share a name.

Can I theme it?

Every colour and the radius are CSS variables. Override a few and everything follows.
