Syntax highlighting

Code is highlighted at build time by Shiki, so pages ship coloured HTML and no highlighting JavaScript. Supported languages: html, css, ts/js, json, bash, toml, md, xml/svg and jinja (Nunjucks). Anything else is shown escaped, uncoloured.

Colours are CSS variables, --code-token-keyword, --code-token-string and so on, defined for light and dark next to the other tokens. Override them to restyle every code block.

{% call code("css", title="src/styles.css") %} :root { --code-token-keyword: var(--color-fuchsia-600); --code-token-string: var(--color-teal-700); } {% endcall %}

Package-manager commands

Install commands come in bun, npm, pnpm and yarn flavours. Switch tabs here and every command block on every page follows. The choice is saved in localStorage and restored on your next visit.

{{ cli("add htmx-ui htmx.org add-dev tailwindcss") }}

With the Nunjucks macro, write each line with an action and it's translated for each manager:

{% call code("jinja", title="page.html") %} {% raw %}{% from "components/code/code.html" import cli %} {{ cli("add htmx-ui htmx.org add-dev tailwindcss run dev") }}{% endraw %} {% endcall %} {{ classes([ ["init", "npm init -y · pnpm init · yarn init -y · bun init -y"], ["install", "npm install · pnpm install · yarn install · bun install"], ["add", "npm install · pnpm add · yarn add · bun add"], ["add-dev", "npm install -D · pnpm add -D · yarn add -D · bun add -d"], ["run", "npm run · pnpm run · yarn run · bun run"], ["exec", "npx · pnpm dlx · yarn dlx · bunx"], ["create", "npm create · pnpm create · yarn create · bun create"], ["anything else", "Shown unchanged on every tab, e.g. mkdir my-app && cd my-app"] ], heading="Action") }}

The commands live in htmx-ui/components/code/package-managers.json; add a manager or change the default there.

Markup

The copy button is an icon-only clipboard button with data-clipboard-target="pre:not([hidden]) code": the clipboard copies the nearest match, which is the visible <code> in its own block, and shows a green tick for two seconds. .code-copy mutes it until hovered; without a header it floats over the top-right corner of the code.

{% call demo("block p-4 sm:p-6") %}
app.ts 
initComponents(document);
{% endcall %}

For tabs, put data-tabs on the block (plus data-tabs-sync="key" to sync), .tabs-trigger buttons with data-tab in a .tabs-list.tabs-line.code-tabs strip in the header (underlined tabs, fitted to it), and one <pre data-tab-panel> per tab. See Tabs.

Nunjucks macros

{% call code("jinja", title="page.html") %} {% raw %}{% from "components/code/code.html" import code, code_block, code_tabs, cli %} {% call code("html", title="index.html") %} {% endcall %} {{ code_block(some_string, "ts") }} {{ code_tabs([{ id: "a", label: "a.ts", lang: "ts", source: a }], sync="files") }}{% endraw %} {% endcall %}

Bodies are de-indented and escaped. Wrap Nunjucks syntax in {% raw %} so it's shown, not run.
