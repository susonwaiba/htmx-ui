Markup

  • Any button with data-clipboard copies when clicked. Say what with data-clipboard-text (see What it copies).
  • Add .clipboard and put both of its looks inside: .clipboard-idle (a copy icon, a label or both) and .clipboard-done (a tick, "Copied").
  • After a copy the button gets data-copied for two seconds, which shows .clipboard-done with a green tick. The two looks share one space, so the button keeps its width when "Copy" becomes "Copied".
  • An icon-only button needs aria-label="Copy" (or "Copy link", "Copy API key"…).

Screen readers hear "Copied" (or "Copy failed") through a polite live region, because a button's changed text isn't read out by itself. Set data-clipboard-announce to say something else, and data-clipboard-timeout (ms) to keep the tick longer.

Icon, label or both

Leave out what you don't need: the icons, the labels, or one of each.

{% call demo("gap-4") %} {{ clipboard(text="Icon and label") }} {{ clipboard(text="Icon only", icon_only=true) }} {{ clipboard(text="Label only", icon=false, copied_icon=false) }} {{ clipboard(text="Custom labels", label="Copy link", copied="Link copied") }} {% endcall %}

Variants

Every button variant works. The tick is green on outline, ghost, secondary and link buttons; on a filled primary or danger button it keeps the button's text colour, so it stays readable.

Copy tag

A .clipboard-tag is a monospace chip that copies the text it shows: an install command, an id, a coupon code. The whole chip is the button. Put the text in a data-clipboard-content element and the two icons in a .clipboard span; give the button an aria-label. Long text is cut short with an ellipsis, but the whole of it is copied.

{% call demo("flex-col gap-4") %}
{{ clipboard_tag("bun add htmx-ui", size="sm") }} {{ clipboard_tag("bun add htmx-ui") }} {{ clipboard_tag("bun add htmx-ui", size="lg") }}
{{ clipboard_tag("WELCOME20", variant="outline") }} {{ clipboard_tag("ord_8f2a91c4e7d0", variant="outline", size="sm", label="Copy order id") }} {{ clipboard_tag("hx_secret_••••3f9a", copy="hx_secret_example_0c9e3f9a", variant="outline", label="Copy secret key") }}
{% endcall %}

The last one shows a shortened key but copies the whole of it: copy= in the macro, which writes data-clipboard-text. .clipboard-tag-sm / .clipboard-tag-lg size it and .clipboard-tag-outline gives it a border instead of a fill.

What it copies

The first of these that is set:

AttributeCopies
data-clipboard-text="…"That text.
data-clipboard-url="/page.md"The text of that URL, fetched when clicked. The docs' "Copy Markdown" button works this way.
data-clipboard-target="selector"The nearest element matching the selector, looking outward from the button: its own block first, then further out, so #id works and so does a class shared by many blocks (.message-content, or pre:not([hidden]) code in code blocks). For an input, textarea or select, its value, read when clicked (so it copies what the user typed); for any other element, its text.
data-clipboard-contentThe text of that element inside the button (a copy tag).

Browsers and platforms

  • Secure pages (https, and localhost while developing) copy with the asynchronous Clipboard API, supported by every current browser on desktop, Android and iOS.
  • Plain http, older browsers and iframes without the clipboard-write permission fall back to document.execCommand("copy") on a hidden, read-only textarea. It is selected the way iOS Safari needs, doesn't open the phone keyboard or zoom the page, and focus goes back where it was.
  • If both fail (a browser that blocks clipboard access), the button gets data-copy-failed for the same two seconds, its icon turns red, "Copy failed" is announced and clipboard:error fires.
  • Browsers only allow copying in response to the user, so call it from a click, not on page load. With data-clipboard-url, the fetch is handed to the clipboard as a promise where the browser accepts one (Safari, Chrome), so the click still counts once the text arrives.

Events and htmx

A copy fires a bubbling clipboard:copy with detail.text (or clipboard:error). Use it as an htmx trigger to record the copy, or add a toast with data-toast on the same button:

{% call demo("gap-4") %} {{ clipboard(text="https://example.com/r/8f2a", label="Copy referral link", attrs={"data-toast": "Link copied", "data-toast-type": "success"}) }} {% endcall %} {% call code("html", title="Count copies on the server") %} {% raw %}{% endraw %} {% endcall %}

Copy buttons htmx swaps in work at once: the behaviour runs again on new content.
