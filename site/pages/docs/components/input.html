Usage

Add .input to any text-like <input>. It fills its container's width; constrain it with a max-w-* utility or a wrapper. Every input needs a label: wrap it in a field with a .field-label, or give it an aria-label.

States

Disabled

The disabled attribute fades the input; inside a field, the label fades too.

{% call demo("flex-col") %}
{% endcall %}

Required

A field holding a required input marks its label with an asterisk automatically.

{% call demo("flex-col") %}
{% endcall %}

Error, warning, success

Set aria-invalid="true" for an error (the border turns red; so does the field's label). Native validation styles the same way once the user has interacted (:user-invalid). For softer states, add .input-warning or .input-success. Pair each with a message from the field classes and link it with aria-describedby.
