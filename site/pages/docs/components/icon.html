Usage

Icons are 24×24 Lucide-style SVGs drawn with stroke="currentColor", so they take the text colour. Size them with Tailwind (size-4, size-5…). The macro inlines the file's <svg> and adds your class:

{% call code("jinja", title="page.html") %} {% raw %}{% from "components/icon/icon.html" import icon %} {{ icon("sun") }} {# decorative: aria-hidden #} {{ icon("info", "size-5", label="Note") }} {# meaningful: role="img" + aria-label #} {{ icon("sun", mode="img") }} {# pointing at a copy of the file #}{% endraw %} {% endcall %}

{% call demo() %} {{ icon("palette", "size-6 text-primary") }} {{ icon("palette", "size-6", mode="img") }} {% endcall %}

In img mode the bundler copies the SVG next to the page with a content hash in its name (sun-a1b2c3.svg), so a changed icon is never served stale.

Separately, this site's build copies the package's icons/ to dist/assets/icons/ with unchanged names. /assets/icons/<name>.svg is therefore a stable URL for linking from other sites, emails or docs, e.g. /assets/icons/sun.svg.

Any SVG

The svg() template function inlines any SVG file under a template root (your project, then htmx-ui), setting or overriding attributes on its root element:

{% call code("jinja") %} {% raw %}{{ svg("images/logo.svg", { class: "h-8 w-auto", "aria-label": "HTMX UI", role: "img" }) }}{% endraw %} {% endcall %}

Adding an icon

  1. Save a 24×24 SVG with stroke="currentColor" (or fill="currentColor") as icons/<name>.svg in your project; your file wins over a package icon of the same name. Lucide icons drop straight in.
  2. Use it: {{ icon("<name>") }}. A misspelt name fails the build.
