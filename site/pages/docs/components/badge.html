Status

Soft, tinted variants for status. They use the --info, --success, --warning and --danger tokens.

{% call demo() %} Info Success Warning Danger {% endcall %}

Add .badge-solid to fill one with its colour, for status that has to stand out, such as a destructive one.

{% call demo() %} Info Success Warning Destructive {% endcall %}

With a dot or icon

Icons go before or after the text and are sized to it.

{% call demo() %} Operational Degraded {{ icon("badge-check") }} Verified {{ icon("star") }} Featured Next {{ icon("arrow-right") }} {% endcall %}

With a spinner

A spinner inside a badge takes the icon size. With .htmx-indicator, it takes no space until the badge's request starts.

{% call demo() %} {{ spinner(label=none) }} Syncing {{ spinner(label=none) }} Deploying Queued {% endcall %}

Link

A badge can be an <a> (or a <button>): it gets a hover state in its variant and a focus ring.

{% call demo() %} Open {{ icon("arrow-right") }} {{ icon("link") }} Docs #htmx {{ icon("check") }} Passing View changelog {{ icon("external-link") }} {% endcall %}

Custom colours

For a tinted badge in any colour, add .badge-tone and set --badge-tone: it gets the same border, background and hover as the status variants, and works with .badge-solid. For anything else, colour utilities override the badge's own colours.

{% call demo() %} Design Research Shipped Utilities Gradient {% endcall %}
