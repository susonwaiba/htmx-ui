Six ready-made themes ship under htmx-ui/themes/. Using one takes the same two steps as on the Theming page — import the file, set data-theme — so this page is the catalogue instead: what each one looks like, every value it sets, and a button that puts it on this site.

{% call code("css", title="src/styles.css") %} @import "tailwindcss"; @import "htmx-ui/styles.css"; /* One, or several — an attribute picks which applies where. */ @import "htmx-ui/themes/aurora.css"; @import "htmx-ui/themes/onyx.css"; {% endcall %} {% call code("html") %}
…
{% endcall %}

Applying one is live: the buttons below — and the picker in this site's header — are plain data-theme-palette buttons wired by initTheme() (Switching themes). Each writes the site-wide data-theme and remembers the choice. Dark mode is independent, so flip that too and every theme shows its dark side.

All six redefine the same small set — --radius, --primary, --primary-foreground, --ring and --brand-gradient — plus a tinted light --background where it suits, and in dark mode a brighter --primary, a new --brand-gradient and the --background / --surface / --border trio. Every other token keeps the library's value, so components never shift. Each file is a few hundred bytes: import all the ones you might switch between and the picker will offer exactly those.
