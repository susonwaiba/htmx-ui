Markdown pages

Add .md to any docs URL to get the page as Markdown: /docs/components/button.md, /docs.md. Each file starts with frontmatter (title, description, URL, section). Live examples become their source code, and reference tables become Markdown tables. The Copy Markdown button at the top of every page copies it for pasting into a chat.

Every sections[].id is a heading anchor, so url + "#" + id opens that exact section. An MCP server or a search box can list pages from these files and link straight to the right place.

How it's generated

Nothing is written by hand. At build time bun/site.ts renders every page, converts the article body to Markdown (bun/markdown.ts), and writes the indexes. The dev server generates the same files on request.

  • Page order follows the docs navigation in site/data/docs-nav.json.
  • Absolute URLs (and the URLs in the prompts above) use the SITE_URL environment variable, falling back to url in site/data/site.json.
  • Every docs heading gets an id and a # link, so sections can be linked directly.
  • Add data-md-skip to an element to leave it out of the Markdown and the search text (purely visual blocks).
