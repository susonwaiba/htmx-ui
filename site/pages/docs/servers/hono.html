htmx-ui-engine/hono exports one function: htmxUi() returns middleware that answers the paths your own handlers don't. Hono is Web-standard, so it runs on Node, Bun, Deno, workers and edge runtimes.

{{ cli("add hono") }}

Mount it

Hono runs middleware in registration order and stops at the first handler that answers, so register htmx-ui last:

{% call code("ts", title="server.ts") %} import { Hono } from "hono"; import { htmxUi } from "htmx-ui-engine/hono"; const app = new Hono(); app.get("/api/invoices", (c) => c.json(invoices.list())); app.post("/api/invoices", async (c) => c.json(await invoices.create(await c.req.json()), 201)); app.use(htmxUi()); // pages at their routes, assets, public files, 404.html export default app; {% endcall %}

Paths that match nothing get the built 404.html, or Hono's own 404 when you didn't build one. With app.request() or a test client, the same app answers in-process.

Options

htmxUi() takes the same options as createSite():

{% call code("ts", title="server.ts") %} import { createSite } from "htmx-ui-engine"; import { htmxUi } from "htmx-ui-engine/hono"; const site = await createSite({ root: "../marketing" }); app.use(htmxUi({ site })); {% endcall %} {{ classes([ ["root", "Project root, where htmx-ui.config.ts and pages/ live. Default: process.cwd()."], ["config", "A UserConfig or ResolvedConfig to use instead of reading htmx-ui.config.ts."], ["context", "Values for every render, on top of the config's globals."], ["asset(file, page)", "URL for asset() in site.render() and site.fragment()."], ["site", "A site from createSite(), to render pages and fragments from the same instance."], ["cache", "Keep compiled templates between requests. Default true; false re-reads every template on every render."] ], heading="Option") }}

Fragments

htmx swaps HTML, so return HTML. site.fragment() renders a template — with your macros, components and asset() — without a document shell:

{% call code("ts", title="server.ts") %} app.get("/api/invoices/:id/refund", (c) => { refund(c.req.param("id")); return c.html(site.fragment("partials/invoice-row.html", { invoice: invoices.get(c.req.param("id")) })); }); {% endcall %}

To render a whole page from request data, use site.render(url, context) and c.html() it — see Server frameworks for the whole picture.

Build first

The middleware serves dist/, not your templates, so render the site before starting the server. While you work on pages, htmx-ui dev is the quicker loop, with hot reload and mock endpoints:

{% call code("bash", title="Terminal") %} htmx-ui build && node server.js {% endcall %} {% endblock %}
