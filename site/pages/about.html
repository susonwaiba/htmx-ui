About this project

HTMX UI is a component library for server-rendered apps that use htmx. Components are plain HTML styled with Tailwind CSS, plus a few small behaviours that survive htmx swaps.

This site is built with the library itself: each file in site/pages is a route, rendered with Nunjucks at build time and bundled by Bun.

Read the documentation or browse the components.
