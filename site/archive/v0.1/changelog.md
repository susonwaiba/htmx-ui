# Changelog

Every release of HTMX UI, newest first. The project follows semantic versioning.

1. [v0.1.0](/docs/v0.1/changelog/0.1.0): First release: design tokens, light and dark themes, twenty components including forms, toggles and loading states, syntax highlighting, versioned and agent-ready docs; plus htmx-ui-engine (dev server and builds on Bun or Node) and create-htmx-ui.

## Versioning

Versions follow [semantic versioning](https://semver.org). Before 1.0, minor versions (0._x_.0) may rename classes or tokens; each release page lists what to change.
