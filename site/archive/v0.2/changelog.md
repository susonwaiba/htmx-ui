# Changelog

Every release of HTMX UI, newest first. The project follows semantic versioning.

1. [v0.2.0](/docs/v0.2/changelog/0.2.0): Plugins, with docs, versions and search as the first three; named template roots; serving a site from your own backend with five adapters (Elysia, Fastify, Koa, Express, Hono) and a default 404 page; and 37 new components, from dialogs, menus and toasts to an AI chat stack.
2. [v0.1.0](/docs/v0.2/changelog/0.1.0): First release: design tokens, light and dark themes, twenty components including forms, toggles and loading states, syntax highlighting, versioned and agent-ready docs; plus htmx-ui-engine (dev server and builds on Bun or Node) and create-htmx-ui.

## Versioning

Versions follow [semantic versioning](https://semver.org). Before 1.0, minor versions (0._x_.0) may rename classes or tokens; each release page lists what to change.
